AI Video Generator Studio

A local-first studio interface for generating images and video clips, planning multi-scene videos, adding narration and subtitles, and organizing outputs by job.

View source repository
Overview

The work

Developed a Windows-friendly application with a FastAPI backend and custom studio interface, task-based provider routing, visible job states and FFmpeg-based output assembly.

What it covers

  • Image and single-clip generation workflow
  • Multi-scene storyboard and narration flow
  • SRT caption generation and optional burn-in
  • Project library for completed, running and failed jobs
  • Provider settings, direct downloads and clear error states

Technology

The implementation and project materials identify the following technologies and workflow areas. This list describes the project stack, not a claim that every service is running on the public internet.
